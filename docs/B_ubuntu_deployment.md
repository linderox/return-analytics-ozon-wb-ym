- **Дата создания:** 2026-06-24
- **Дата обновления:** 2026-06-24
- **Изменения:** Настройка прав доступа для SQLite

## Развертывание
1. Клонируйте репозиторий
2. Настройте systemd сервис для FastAPI
3. **Важно:** Убедитесь, что у пользователя, под которым запущен сервис, есть права на запись в директорию backend для создания и обновления `returns_history.db`.
