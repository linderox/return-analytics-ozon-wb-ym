# Принцип работы скрипта ym_returns_fashion.gs

## Общая логика

Скрипт выгружает возвраты и невыкупы из Яндекс Маркета через API и записывает их в Google Sheets.

### Шаг 1 — Получение данных из API

Функция `getYmData()` делает запросы к YM API с пагинацией, собирая все возвраты за последние `DAYS_TO_FETCH` дней. На каждой странице логирует количество полученных записей.

### Шаг 2 — Фильтрация

Из всех полученных записей оставляем только те, у которых `shipmentStatus === 'PICKED'` — то есть фактически выданные магазину. Невыданные (ожидают на складе, в пути и т.д.) игнорируются.

### Шаг 3 — Сравнение с таблицей

Скрипт читает все существующие строки из листа и строит карту `ID → {номер строки, значения полей}`.

Затем для каждой записи из API выполняется одно из трёх действий:

| Ситуация | Действие | Цвет строки |
|---|---|---|
| ID не найден в таблице | Добавить в конец таблицы | Серый `#efefef` |
| ID есть, поля не изменились | Пропустить | Без изменений |
| ID есть, поля изменились | Перезаписать строку, записать в лог что изменилось | Жёлтый `#fff2cc` |

> **Примечание:** поле `Дата обновления` (`updateDate`) исключено из сравнения — оно меняется при каждом обращении к API и создавало бы лишний шум. Значение в таблице при этом всё равно обновляется.

### Шаг 4 — Запись

- Новые строки дозаписываются в конец одним батчем через `sheet.getRange(lastRow + 1, ...).setValues(newRows)`.
- Изменившиеся строки перезаписываются точечно по номеру строки.
- Существующие неизменённые строки **не трогаются совсем** — ручная покраска пользователя сохраняется.

---

## Лог изменений

При обнаружении изменённых полей в лист «Лог» добавляется запись вида:

```
[YM] Обновлена запись ID=26697998: Статус возврата денег: "" → "REFUNDED"
```

Итоговая строка лога по каждому запуску:

```
[YM] Добавлено новых: 2, обновлено: 1
```

---

## Цветовая схема

| Цвет | Значение |
|---|---|
| Серый `#efefef` | Новая запись, только что добавлена скриптом |
| Жёлтый `#fff2cc` | Существующая запись — одно или несколько полей изменились по данным API |
| Без заливки / ручной цвет | Запись без изменений, цвет задан пользователем вручную |

## Конфигурация (начало файла)

```javascript
const API_KEY = '...';          // Токен Яндекс Маркета
const CAMPAIGN_ID = '...';      // ID кампании
const SHEET_NAME = 'Возвраты YM';
const DAYS_TO_FETCH = 30;       // Глубина выгрузки в днях
```

Состав колонок и логика извлечения полей из JSON описаны в массиве `COLUMNS_CONFIG`.
