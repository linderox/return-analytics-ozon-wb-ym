# [G] Структура проекта

- **Дата создания:** 2026-06-24
- **Дата обновления:** 2026-06-24
- **Изменения:** Первоначальное описание структуры

Проект организован как монорепозиторий, разделенный на логические блоки для удобства масштабирования и поддержки.

```
.
├── core/                   # Общая логика
│   ├── db/                 # Работа с базами данных (Supabase, SQLite)
│   └── gs_handler.py       # Синхронизация с Google Sheets
├── docs/                   # Документация (индексированная A-G)
├── mappings/               # JSON описания полей маркетплейсов
├── tests/                  # Набор тестов (Backend & Frontend)
├── tools/                  # CLI инструменты для синхронизации
│   ├── ozon/
│   ├── wb/
│   └── ym/
├── webapp/                 # Основное приложение
│   ├── backend/            # FastAPI (Python)
│   │   ├── routers/        # Эндпоинты (shops, returns, billing, admin)
│   │   ├── services/       # Бизнес-логика синхронизации
│   │   └── main.py         # Точка входа
│   └── frontend/           # Vue 3 (Vite, Tailwind, Claude 2026 UI)
│       ├── src/
│       │   ├── views/      # Страницы (Dashboard, Billing, Admin)
│       │   └── lib/        # Утилиты (Supabase client)
└── run_tests.sh            # Скрипт запуска всех тестов
```

### Описание ключевых директорий
- **webapp/backend:** Использует абсолютные импорты. Весь запуск должен происходить из корня проекта через `PYTHONPATH=.`.
- **webapp/frontend:** Следует стилистике Claude Code 2026. Основные цвета: #FBF0D3 (фон), #D97706 (акцент).
- **core/db/database.py:** Реализует гибридную схему: метаданные в облаке (Supabase), тяжелая история локально (SQLite).
