# Принцип работы скрипта wb_returns_fashion.gs

## Общая логика

Скрипт выгружает возвраты из Wildberries через API и записывает их в Google Sheets.

### Шаг 1 — Получение данных из API

Функция `getWbData()` делает одиночный GET-запрос к WB Seller Analytics API. Пагинация не используется — API возвращает все записи за период одним ответом. Период задаётся константой `DAYS_TO_FETCH` (по умолчанию 30 дней).

Авторизация: заголовок `Authorization: <JWT-токен>`.

### Шаг 2 — Фильтрация

Из всех полученных записей оставляем только те, у которых `status === 'Выдано'` — то есть фактически переданные обратно продавцу. Остальные статусы (в пути, на складе и т.д.) игнорируются.

### Шаг 3 — Сравнение с таблицей

Скрипт читает все существующие строки из листа и строит карту `srid → {номер строки, значения полей}`.

Затем для каждой записи из API выполняется одно из трёх действий:

| Ситуация | Действие | Цвет строки |
|---|---|---|
| `srid` не найден в таблице | Добавить в конец таблицы | Серый `#efefef` |
| `srid` есть, поля не изменились | Пропустить | Без изменений |
| `srid` есть, поля изменились | Перезаписать строку, записать в лог что изменилось | Жёлтый `#fff2cc` |

> **Примечание:** у WB нет поля-таймстампа, который меняется при каждом запросе, поэтому все поля участвуют в сравнении без исключений.

### Шаг 4 — Запись

- Новые строки дозаписываются в конец одним батчем через `sheet.getRange(lastRow + 1, ...).setValues(newRows)`.
- Изменившиеся строки перезаписываются точечно по номеру строки.
- Существующие неизменённые строки **не трогаются совсем** — ручная покраска пользователя сохраняется.

---

## Лог изменений

При обнаружении изменённых полей в лист «Лог» добавляется запись вида:

```
[WB] Обновлена запись srid=abc123: Статус возврата: "Ожидает" → "Выдано"
```

Итоговая строка лога по каждому запуску:

```
[WB] Добавлено новых: 3, обновлено: 1
```

---

## Цветовая схема

| Цвет | Значение |
|---|---|
| Серый `#efefef` | Новая запись, только что добавлена скриптом |
| Жёлтый `#fff2cc` | Существующая запись — одно или несколько полей изменились по данным API |
| Без заливки / ручной цвет | Запись без изменений, цвет задан пользователем вручную |

## Конфигурация (начало файла)

```javascript
const API_KEY = '...';      // JWT-токен Wildberries
const DAYS_TO_FETCH = 30;   // Глубина выгрузки в днях (макс. 31 по правилам API)
// SHEET_NAME задаётся в другом файле проекта
```

Состав колонок (19 штук) задан в массиве `COLUMNS_CONFIG`:
`srid`, `orderDt`, `nmId`, `brand`, `subjectName`, `techSize`, `barcode`, `shkId`, `returnType`, `reason`, `status`, `isStatusActive`, `readyToReturnDt`, `completedDt`, `expiredDt`, `dstOfficeId`, `dstOfficeAddress`, `orderId`, `stickerId`.
