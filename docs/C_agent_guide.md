# [C] Инструкция для Агентов (Agent Guide)

- **Дата создания:** 2026-06-24
- **Дата обновления:** 2026-06-24
- **Изменения:** Описание гибридной архитектуры хранения

## Хранение данных
- **Supabase (PostgreSQL):** Хранит только критические данные пользователей (профили, список магазинов, подписки).
- **SQLite (`returns_history.db`):** Хранит глубокую историю возвратов для каждого пользователя. Это позволяет хранить неограниченный объем данных локально.
