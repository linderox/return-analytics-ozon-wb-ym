# [E] Панель администратора

- **Дата создания:** 2026-06-24
- **Дата обновления:** 2026-06-24
- **Изменения:** Добавлена инструкция по управлению пользователями

## Доступ
- Для доступа к панели администратора (`/admin`) у пользователя в таблице `public.profiles` должно быть установлено поле `is_admin = TRUE`.

## Возможности
- Просмотр списка всех зарегистрированных пользователей.
- Отображение количества магазинов у каждого пользователя.
- Детальный просмотр магазинов конкретного пользователя:
  - Тип маркетплейса.
  - Дата последней синхронизации.
  - **Количество строк в локальной базе SQLite.**

## Локальное хранилище
- Данные о количестве строк подтягиваются напрямую из `returns_history.db` на сервере backend.
